# 검색광고 매체별 광고문구 가이드 (자동생성 기능용)

> 기준일: 2026-08-04 / 함께 제공되는 `search_ad_copy_spec.json`이 기계 판독용 원본입니다.

## 0. 개발자를 위한 3줄 요약

첫째, **글자수 카운팅 방식이 매체마다 다릅니다.** 네이버·카카오는 한글·영문·공백 구분 없이 1자=1로 세지만, 구글은 한도(limit)는 고정한 채 **한글 등 전각 문자를 1자당 2로** 계산합니다. 따라서 카운터를 두 종류(`GRAPHEME_1`, `GOOGLE_CJK_2`)로 분리 구현해야 합니다.

둘째, **자동생성 → 사전필터 → 매체검수**의 3단계 중 앞 두 단계에서 최상급 표현·특수문자·중복 문구를 잡아내면 반려율이 크게 낮아집니다. 규정 대부분은 "정성 심사"라 100% 사전차단은 불가하지만, 명백한 위반 패턴은 정규식으로 걸러낼 수 있습니다.

셋째, **확정 수치와 미검증 수치를 구분**하세요. 파워링크 제목 15자/설명 45자, 카카오 제목 15자/설명 45자, 구글 제목 30·설명 90은 공식 확정값입니다. 확장소재 세부 글자수 상당수는 매체 UI 개편으로 자주 바뀌므로 명세에 `review_required`로 표기해 두었고, 개발 확정 전 등록 화면에서 실측을 권장합니다.

## 1. 매체별 핵심 소재 구조 및 글자수

### 1-1. 네이버 검색광고 (파워링크 기준)

| 필드 | 글자수 | 개수 | 상태 |
|---|---|---|---|
| 제목 | 최대 15자 | 소재당 1 | 확정 |
| 설명 | 20자~45자 | 소재당 1 | 확정 |
| 추가제목(확장) | 최대 15자 | 최대 2 | 확정 |
| 홍보문구(확장) | 최대 14자 | 1 | 확정 |
| 추가설명(확장) | 최대 45자 | 1 | 확정 |
| 서브링크(확장) | 제목 6자 내외 | 최대 4 | 개수 확정/글자수 확인필요 |
| 가격링크(확장) | 이름 11자, 가격 최대 99,999,999원 | 최대 3 | 확정 |

파워링크 이미지는 5MB 미만·2000×2000px 이하 정사각형이며, 이미지 내부에 전화번호·URL·이메일 텍스트를 넣으면 반려됩니다. 파워콘텐츠와 브랜드검색의 문구별 정확한 글자수는 공개 자료로 확정되지 않아 등록 화면 확인이 필요합니다.

### 1-2. 카카오 키워드광고

| 필드 | 글자수 | 개수 | 상태 |
|---|---|---|---|
| 제목 | 최대 15자 | 소재당 1 | 확정 |
| 설명문구 | 최대 45자 | 소재당 1 | 확정 |
| 추가제목(확장) | 최대 24자 | 1 | 확인필요 |
| 부가링크(확장) | 각 6자 | 최대 4 | 확인필요 |
| 말머리(확장) | 최대 17자 (할인/이벤트/인증/연관기사 중 택1) | 1 | 확인필요 |
| 가격테이블(확장) | 각 9자 | 최대 3 | 확인필요 |

표시 URL은 캠페인의 비즈채널 URL이 자동 적용되며 소재 단계에서 수정할 수 없습니다. 글자수는 한글·영문·숫자·공백 모두 1자로 계산합니다.

### 1-3. Google Ads 반응형 검색광고(RSA)

| 필드 | 한도(카운트) | 한글 실질 | 개수 | 상태 |
|---|---|---|---|---|
| 제목(Headline) | 30 | 15자 | 3~15 | 확정 |
| 설명(Description) | 90 | 45자 | 2~4 | 확정 |
| 표시경로(Path) | 15 | 7자 | 2 | 확정 |
| 사이트링크 텍스트 | 25 | 12자 | 최소 2 | 확정 |
| 콜아웃 | 25 | 12자 | 최소 2, 최대노출 10 | 확정 |

**한글 카운팅이 핵심입니다.** 제목 한도는 30이지만 한글은 1자당 2를 소모하므로 실제로는 15글자까지만 입력됩니다. 게재 시 시스템이 제목·설명을 자동 조합(노출당 최대 제목 3 + 설명 2)하며, 특정 위치에 고정(pinning)할 수 있으나 단일 고정은 광고 강도를 떨어뜨려 위치당 2~3개를 권장합니다.

## 2. 글자수 카운팅 구현 (가장 흔한 버그 지점)

```javascript
// 네이버·카카오: 모든 문자 1카운트 (공백 포함, 서로게이트 안전)
function countGrapheme1(str) {
  return Array.from(str).length;
}

// 구글: ASCII=1, 전각 CJK=2
function countGoogleCJK(str) {
  let n = 0;
  for (const ch of str) {
    const cp = ch.codePointAt(0);
    const isCJK =
      (cp >= 0xAC00 && cp <= 0xD7A3) ||  // 한글 음절
      (cp >= 0x1100 && cp <= 0x11FF) || (cp >= 0x3130 && cp <= 0x318F) || // 한글 자모
      (cp >= 0x4E00 && cp <= 0x9FFF) ||  // CJK 한자
      (cp >= 0x3040 && cp <= 0x30FF) ||  // 가나
      (cp >= 0xFF00 && cp <= 0xFF60);    // 전각 영숫자/기호
    n += isCJK ? 2 : 1;
  }
  return n;
}
```

동일한 "테스트문구"라도 네이버에서는 5자, 구글에서는 10카운트로 계산됩니다. 자동생성 결과를 각 매체 카운터에 통과시킨 뒤에만 유효 소재로 취급하세요.

## 3. 금지·심의 표현 (사전 필터 설계)

### 3-1. 세 매체 공통 금지

가장 중요한 것은 **최상급·배타성 표현**입니다. "최고, 1위, 최저, 유일, 국내 유일, No.1, Best" 같은 표현은 세 매체 모두 객관적 증빙(공신력 있는 조사기관 자료, 수상 내역, 통계) 또는 랜딩페이지 내 근거가 없으면 사용할 수 없습니다. 자동생성 단계에서 이런 어휘가 나오면 차단하거나 "근거 필드 필수" 플래그를 띄우는 것이 안전합니다. 이 외에 허위·과장, 부분 사실의 전체화, 부당한 비교·경쟁사 비방, 비속어·혐오·차별 표현, 상표권·초상권 침해, 그리고 **문구와 실제 랜딩페이지 내용의 불일치**가 공통 반려 사유입니다.

### 3-2. 특수문자 규칙 (매체별 차이)

네이버는 과도한 특수문자와 반복 기호(`!`, `^^`, `*`) 사용을 지양하며 이모지는 비권장입니다. 카카오는 의미 전달 목적일 때만 특수문자를 허용하고 반복형(`!!!!`), 이모티콘(`^^`, `ㅠㅠ`), 장식 기호(`☆ ○ ◇ ♡` 등)는 불가합니다. 구글은 가장 명시적이어서 연속 반복(`!!`), 문자 내 기호 치환(`fl@wers`), 구두점 분해(`F.L.O.W.E.R.S`), 장식용 별표(`*text*`), 이모지, 반각 가타카나, 위첨자를 모두 금지합니다.

정규식 예시(공통 사전 필터):

```javascript
const filters = [
  { name: "반복문장부호", re: /([!?.])\1{1,}/ },        // !! ?? ..
  { name: "이모지",       re: /\p{Extended_Pictographic}/u },
  { name: "장식기호",     re: /[☆★○◇□△▲♡♧♨☏☞♬]/ },
  { name: "장식별표",     re: /\*[^*]+\*/ },
  { name: "전체대문자",   re: /\b[A-Z]{5,}\b/ },          // 구글 전용
];
```

### 3-3. 대소문자·맞춤법 (구글 중점)

구글은 전체 대문자(`FLOWERS`)와 눈속임식 대소문자(`FlOwErS`)를 금지하되 통용 약어·쿠폰 코드·브랜드명은 예외로 둡니다. 세 매체 모두 맞춤법·띄어쓰기 정확성을 요구하며, 구글은 추가로 **같은 광고그룹·캠페인·계정 내 애셋 간 중복 문구**를 금지하므로 자동생성 시 중복 검사 로직이 필요합니다.

### 3-4. 업종별 심의

의료·병의원은 의료광고 사전심의 대상으로 심의필 번호가 필요하고, 건강기능식품은 질병 예방·치료 효능 표현이 금지됩니다. 금융·대출·보험은 금리·수수료 필수 고지와 준법감시 준수가 요구됩니다. 카카오는 담배·도박·불건전 채팅·종교·게임 아이템 현금거래 등 약 10종 업종의 광고 등록 자체를 금지합니다.

## 4. 효과적인 문구 작성법 (CTR 향상)

자동생성 프롬프트에 다음 원칙을 규칙으로 주입하면 클릭률이 높은 소재가 나올 확률이 올라갑니다.

**검색 의도(키워드)를 제목에 반영하세요.** 사용자가 검색한 키워드가 제목에 포함될수록 관련성이 높게 인식되고 볼드 처리로 시각적 주목도도 올라갑니다. 자동생성 시 타깃 키워드를 제목 앞부분에 배치하도록 지시하는 것이 효과적입니다.

**구체적 숫자와 혜택을 담으세요.** "저렴한 가격"보다 "30% 할인", "빠른 배송"보다 "당일 출고"처럼 정량적 표현이 신뢰와 클릭을 유도합니다. 단, 가격·할인율은 모든 이용자에게 공통 적용되는 기준값만 쓰고 어떤 상품 기준인지 명시해야 반려되지 않습니다.

**명확한 행동 유도(CTA)를 넣으세요.** "지금 상담 신청", "무료 견적 받기", "오늘까지 할인"처럼 다음 행동과 긴급성을 제시합니다. 설명 필드는 제목이 다루지 못한 차별점(품질보증, 배송, A/S, 신뢰 요소)을 보완하는 용도로 씁니다.

**다양성을 확보하세요.** 네이버·카카오는 소재를 여러 개 등록해 성과 기반으로 자동 노출하고, 구글 RSA는 제목 최대 15개·설명 4개를 서로 다른 각도(혜택/가격/신뢰/긴급성/브랜드)로 채울 때 조합 최적화가 잘 작동합니다. 자동생성은 한 소재만 만들지 말고 **서로 겹치지 않는 여러 변형**을 생성하도록 설계하세요.

## 5. AI 프롬프트 설계 팁

**규칙을 시스템 프롬프트에 하드코딩하고, 가변 값은 컨텍스트로 주입하세요.** 매체별 글자수·금지 표현은 매번 바뀌지 않으므로 시스템 프롬프트(또는 매체별 프롬프트 템플릿)에 고정하고, 업종·키워드·랜딩 URL·프로모션 정보만 사용자 컨텍스트로 넘기는 구조가 관리하기 좋습니다.

**글자수는 프롬프트로만 통제하지 말고 반드시 사후 검증하세요.** LLM은 한글 글자수, 특히 구글의 CJK 2배 카운팅을 자주 틀립니다. "제목은 15자 이내"라고 지시하더라도 생성 결과를 2단계 카운터에 통과시키고, 초과 시 재생성하거나 자동 절삭하는 루프를 두어야 합니다.

**JSON 구조화 출력을 강제하세요.** 자유 텍스트 대신 `{"headlines": [...], "descriptions": [...]}` 형태로 받으면 필드별 검증·저장·API 연동이 쉬워집니다. 각 항목에 "왜 이 문구인가"를 함께 받으면 사람이 선별할 때 유용합니다.

**금지 표현은 프롬프트 지시 + 사후 정규식 필터의 이중 방어로.** LLM에 "최상급 표현 금지"를 지시해도 근거 없는 "최고", "1위"가 새어 나올 수 있으므로 3-2·3-3의 정규식 필터를 반드시 후단에 배치합니다. 걸린 소재는 폐기 후 재생성하세요.

**few-shot 예시로 톤을 고정하세요.** 매체 규정을 지키면서 CTR이 검증된 실제 소재 2~3개를 예시로 넣으면 규칙 나열보다 스타일 재현이 잘 됩니다. 업종별로 예시 세트를 나눠두면 품질이 더 안정적입니다.

프롬프트 골격 예시:

```
[역할] 너는 {매체명} 검색광고 카피라이터다.
[제약] 제목 {N}자 이내, 설명 {M}자 이내. (한글 카운팅 방식: {mode})
       최상급/배타성 표현({최고,1위,유일,...}) 금지 — 근거 없으면 사용 불가.
       특수문자 반복·이모지·장식기호 금지. 랜딩 내용과 일치할 것.
[입력] 업종:{industry} / 타깃키워드:{keyword} / 핵심혜택:{benefits} / 프로모션:{promo}
[요구] 서로 겹치지 않는 제목 {H}개, 설명 {D}개를 아래 JSON으로 출력.
       각 제목 앞부분에 타깃키워드 반영, 구체적 숫자·CTA 포함.
[출력형식] {"headlines":[{"text":"","reason":""}], "descriptions":[...]}
```

## 6. 확정값 vs 확인필요 (개발 반영 우선순위)

**공식 확정값(바로 밸리데이션에 사용 가능):** 네이버 파워링크 제목 15자·설명 20~45자, 추가제목 15자×2, 홍보문구 14자, 추가설명 45자, 가격링크 이름 11자×3(최대 99,999,999원); 카카오 제목 15자·설명 45자(표시 URL 비즈채널 고정); 구글 제목 30·설명 90·경로 15 카운트, 사이트링크·콜아웃 25 카운트(한글 12자), 한글 2배 카운팅 규칙.

**확인필요(등록 화면 실측 권장):** 네이버 파워콘텐츠·브랜드검색·서브링크 세부 글자수; 카카오 확장소재 대부분(추가제목 24자, 부가링크 6자, 말머리 17자, 가격테이블 9자 등)은 gitbook 렌더링 추출값; 구글 사이트링크 설명 라인·가격/스니펫 애셋의 CJK 적용 여부, 핀 위치당 최대 개수. 매체가 UI 개편으로 수치를 바꾼 이력이 있으므로 분기별 재검증을 권장합니다.
